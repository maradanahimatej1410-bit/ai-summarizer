# AI Text Summarizer API

## 🚀 Live Demo

https://summarizer-service-230227073831.asia-south1.run.app/

---

## 📌 Project Description

This project is an AI-based text summarization API. It takes input text and returns a concise yet meaningful summary of the given text using Natural Language Processing techniques.

---

## ⚙️ Tech Stack

* Python
* Flask / FastAPI
* NLP (Text Summarization)
* Google Cloud Run

---

## 🔗 API Usage

### Endpoint:

POST /summarize

### Full URL:

https://summarizer-service-230227073831.asia-south1.run.app/summarize

---

### 📥 Sample Input

```json
{
  "text": "Artificial Intelligence is transforming the world rapidly."
}
```

---

### 📤 Sample Output

```json
{
  "summary": "AI is transforming the world."
}
```
